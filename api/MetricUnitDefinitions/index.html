MetricUnitDefinitions

Every unit MetricUnit can be made in, read in, parsed from and written in. This list is where a unit is declared: its id, dimensions, size in SI base units, symbol, measurement system, English names and the other text it may be typed as. MetricUnit, MetricUnitFormatUtils, MetricUnitParseUtils and MetricUnitFallbackStrings all read it. Symbols are the SI ones (or the customary ones for US and imperial units), which do not change with the locale.

To add a unit:

  1. Add a row to the define call for its dimension and system below. See UnitRow for the fields. Give an SI unit prefixes rather than adding its prefixed forms: kilo, nano and the rest are made from it.
  2. Add its id to the UnitId union, with any prefixed forms games commonly name. luau-lsp rejects a row whose id is missing from it; other prefixed ids work at runtime.
  3. Add it to a system's display units in MetricUnitSystems if it should be picked by size.
  4. If it is written by name, add units.<id>.long.<category> and units.<id>.short.<category> for all six plural categories to every Localization/MetricUnitTranslator/<locale>.json.txt: English from this row, the other languages from CLDR's unit patterns. Prefixed forms need no entry; they are written from the prefixes section and the unit's own entry.
  5. Only for a unit games construct constantly, add a named constructor on MetricUnit.

The specs catch a named unit without English names or translation keys, and a unit that does not round-trip through MetricUnit.new and MetricUnit.In.

A unit's id: the singular, camelCase name of the unit. Every id has an entry in MetricUnitDefinitions; reading, formatting and MetricUnit.new all take it, so a typo is a type error.

UnitLike​

</>
type UnitLike = UnitId | Time.TimeUnit | UnitDefinition

A unit id, any of @quenty/time's names for a time unit, such as "hours" or "h", or a unit itself, such as MINI:GetUnit("stud") from a MetricUnitSystem of the game's own scale.

UnitFamily​

</>
type UnitFamily = string

The name of the MetricUnitSystem that declares a unit: "metric", "usCustomary", "imperial", "usCustomaryAndImperial" for the units the United States and Britain share (the inch, mile, pound, mph, BTU, horsepower), "roblox", or a game's own system. Time units and bare rates belong to none, since every system shares them.

UnitForms​

</>
interface UnitForms {
one: string
other: string
}

A singular and plural form of a unit's English name or phrase.

UnitDefinition​

</>
interface UnitDefinition {
id: UnitId
dimensions: Dimensions
factor: number
symbol: string
system: UnitFamily?
names: UnitForms?
shortTemplates: UnitForms?
aliases: {string}?
zero: number?
per: UnitId?
duration: boolean?
prefix: UnitPrefixOf?
}

One unit.

  • factor is its size in SI base units: seconds, metres, kilograms, bytes, kelvin, radians, amperes, moles or candelas, or their product for a derived unit, so a newton is 1 (kg·m/s²) and a kilowatt-hour 3,600,000 (J).
  • names is its American English name, for units written by name. Commonwealth spelling (metre, litre, tonne) is derived.
  • shortTemplates replaces the default short phrase, the symbol after a space, where that reads wrongly (45%, 45°, 1 stud). %s is the number.
  • duration marks the time units, which durations are written in.
  • prefix is set on a unit made from a prefix and another unit, such as kilometer.

The other fields are as in UnitRow.

UnitPrefixOf​

</>
interface UnitPrefixOf {
name: string
base: UnitId
}

For a unit made by prefixing another, the prefix's name and the unit it prefixes: kilometer is kilo and meter. A translator writes it from those two when it has no entry for the unit itself.

UnitRow​

</>
interface UnitRow {
id: UnitId
factor: number
symbol: string
name: string?
plural: string?
short: (string | UnitForms)?
aliases: {string}?
zero: number?
per: UnitId?
prefixes: PrefixSet?
elidesPrefixVowel: boolean?
}

One row of the list below, for a unit of the kind ("length", "speed") and system its define call gives.

  • factor is its size in SI base units.
  • name is its American English singular, for units written by name; plural defaults to name plus "s". Time units are written with @quenty/time's words and bare rates with per phrases, so they have none.
  • short replaces the symbol-after-a-space short phrase, as one template or a singular and plural.
  • aliases is other text it may be typed as when parsed, such as "kph".
  • zero is where the unit's scale starts, in base units. A unit with one is a scale whose readings are points: MetricUnit.new makes absolute values in it. Only the temperature scales have one.
  • per is the time unit a bare rate such as perHour counts per. Hertz is a rate too, but is written by name.
  • prefixes makes a unit for each prefix of a [PrefixSet]: meter with "si" makes kilometer, nanometer and the rest, with names, symbols and aliases from the unit's. A unit declared outright keeps its own row.
  • elidesPrefixVowel drops a prefix's final vowel before the unit, as SI writes kilohm and megohm.

Prefix​

</>
interface Prefix {
name: string
symbol: string
factor: number
}

A metric or binary prefix: kilo is k and 1000.

PrefixSet​

</>
type PrefixSet = "si" | "siMultiples" | "siMultiplesAndBinary"

Which prefixes a unit takes: "si" all twenty-four SI prefixes, "siMultiples" only those of 10 and above (no millibytes), and "siMultiplesAndBinary" those and the binary ones (KiB, MiB).

Functions​

getUnit​

</>
MetricUnitDefinitions.getUnit(unit: UnitLike) → UnitDefinition?

The unit named unit, or nil. Takes any UnitLike, so "hours" and "h" find "hour", and a unit is returned as it is.

getPrefixedUnit​

</>
MetricUnitDefinitions.getPrefixedUnit(
prefix: Prefix,
base: UnitDefinition
) → UnitDefinition?

The unit prefix makes of base, such as kilometer for kilo and meter, or nil when base does not take that prefix.

getDeclaredUnits​

</>
MetricUnitDefinitions.getDeclaredUnits() → {UnitDefinition}

The units declared outright, without their prefixed forms, in the order declared. Cheaper than MetricUnitDefinitions.getUnits; MetricUnitDefinitions.getPrefixedUnit finds the rest.

getUnits​

</>
MetricUnitDefinitions.getUnits() → {UnitDefinition}

Every unit, in the order declared, then every prefixed form. Building the prefixed forms costs a few milliseconds the first time, so look units up with MetricUnitDefinitions.getUnit where you can.

getUnitIds​

</>
MetricUnitDefinitions.getUnitIds(dimensions: Dimensions) → {UnitId}

The ids of every unit of dimensions, in the order declared.

getPrefixes​

</>
MetricUnitDefinitions.getPrefixes() → {Prefix}

Every prefix a unit can take: the twenty-four SI prefixes, smallest first, then the binary ones.

getTimeAliases​

</>
MetricUnitDefinitions.getTimeAliases() → {[string]: UnitId}

@quenty/time's other names for its time units, such as "h" for "hour", mapped to unit ids.

isUnitDefinition​

</>
MetricUnitDefinitions.isUnitDefinition(value: any) → boolean

Whether value is a UnitDefinition, such as one MetricUnitSystem.GetUnit returns.

createUnits​

</>
MetricUnitDefinitions.createUnits(
kind: KindName,
system: string,--

the name of the system that declares them

rows: {UnitRow}
) → {UnitDefinition}

Units for a MetricUnitSystem of a game's own, from rows of one kind as in UnitRow, with their prefixed forms. They are not added to the well-known units; only a system holding them knows them. 

local units = MetricUnitDefinitions.createUnits("length", "space", {
	{ id = "lightYear", factor = 9.4607e15, symbol = "ly", name = "light-year" },
})
