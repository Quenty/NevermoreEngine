MetricUnitFormatUtils

Writes measurements for people, in the style of JavaScript's Intl.NumberFormat with style: "unit": a localized number, then the unit's symbol or name. The unit is picked to suit the value's size unless one is given, so 1,500 N is 1.5 kN. Takes a MetricUnit or its plain MetricUnitData.

Numbers go through NumberLocalizationUtils, so digit grouping and the decimal mark follow the locale. Unit names come from MetricUnitFallbackStrings, and duration words from TimeLocalizationUtils.

A duration is broken into years, months, days, hours, minutes and seconds with MetricUnit's own averaged year and month (a Julian year, and a twelfth of it), not @quenty/time's 365 and 30 days, so MetricUnit.years(1) reads 1 year and MetricUnit.months(1) reads 1 month. Only @quenty/time's words are used. For a clock-style h:mm:ss, or calendar months, hand exact seconds to TimeDurationUtils or Time yourself. 

MetricUnitFormatUtils.format(MetricUnit.meters(1500)) --> 1.5 km
MetricUnitFormatUtils.format(MetricUnit.meters(1500), { unitDisplay = "long" }) --> 1.5 kilometers
MetricUnitFormatUtils.format(MetricUnit.meters(1500):ToUSCustomary()) --> 4,921.26 ft
MetricUnitFormatUtils.format({ amount = 1234.5, dimensions = { length = 1 } }, { unit = "meter", locale = "de-de" }) --> 1 234,5 m
MetricUnitFormatUtils.format(MetricUnit.minutes(90)) --> 1 hour, 30 minutes
MetricUnitFormatUtils.formatUnit("kilowattHour", 3) --> 3 kWh

Functions​

format​

</>
MetricUnitFormatUtils.format(
value: MetricUnit | MetricUnitData,
options: MetricUnitFormatOptions?
) → string

Writes a measurement for the locale in a unit that suits its size, or the one options.unit names. Durations are broken into parts with localized words, temperatures keep whether they are absolute (5 °C) or a difference (5 K), and a rate is written per the shortest time unit it fills at least once (1.6 MB/s).

A value is written in the system of the unit it was made from, so MetricUnit.new(5, "mile") writes miles and MetricUnit.kilometers(8) kilometres. Convert it to write another (MetricUnit.ToMetric, MetricUnit.ToImperial), or use MetricUnitSystem.Format. The locale never chooses a measurement system. 

local length = MetricUnit.meters(2500)
MetricUnitFormatUtils.format(length) --> 2.5 km
MetricUnitFormatUtils.format(length, { unit = "meter" }) --> 2,500 m
MetricUnitFormatUtils.format(length, { unit = "stud" }) --> 8,928.571 studs
MetricUnitFormatUtils.format(length, { unitDisplay = "long", locale = "en-gb" }) --> 2.5 kilometres
MetricUnitFormatUtils.format(length, { maximumSignificantDigits = 1 }) --> 3 km

formatUnit​

</>
MetricUnitFormatUtils.formatUnit(
unit: UnitLike,
amount: number,--

in unit

options: MetricUnitFormatOptions?
) → string

Writes amount of the unit unit, as MetricUnitFormatUtils.format would, without picking another unit. A temperature is absolute on its own scale, so formatUnit("celsius", 20) is 20 °C. 

MetricUnitFormatUtils.formatUnit("kilometerPerHour", 90) --> 90 km/h
MetricUnitFormatUtils.formatUnit("liter", 1, { unitDisplay = "long" }) --> 1 liter
MetricUnitFormatUtils.formatUnit("hours", 1.5) --> 1.5 hours

MetricUnitFormatUtils.formatNumber(2, { minimumFractionDigits = 2 }) --> 2.00
