MetricUnit

A measurement that knows what it measures: an amount in SI base units with integer exponents for each dimension. Time is held in seconds, length in metres, mass in kilograms, memory in bytes, temperature in kelvin, angle in radians, current in amperes, amount of substance in moles and luminous intensity in candelas: the SI base units, with bytes and radians added. Derived quantities such as speed, force, energy and power are products of those, so MetricUnit.new(1, "newton") and MetricUnit.kilograms(1) * MetricUnit.meters(1) / MetricUnit.pow(MetricUnit.seconds(1), 2) are the same value.

Every unit has one id, such as "kilometer", used to read and write it, and one constructor, such as MetricUnit.kilometers. Read a value in any unit of its dimension with MetricUnit.In.

Values are frozen, and every operation returns a new one. * and / combine dimensions, a plain number scales, and +, -, <, <= and == need the same dimension on both sides. A plain 0 is zero of whatever dimension it meets in +, - and the helpers; any other plain number is dimensionless.

A value is either a difference, which scales and adds freely, or absolute, a point on a scale such as a temperature in °C or an instant in time. MetricUnit.new makes points on the temperature scales and differences in every other unit; MetricUnit.point and MetricUnit.difference make either in any unit. Two absolutes subtract to a difference, an absolute and a difference add to an absolute, and an absolute cannot be added to another, negated, multiplied or divided, kelvin included. 

local speed = MetricUnit.kilometers(36) / MetricUnit.hours(1)
speed:In("meterPerSecond") -- 10
speed:In("milePerHour") -- 22.37
speed:GetKind() -- "speed"
MetricUnit.format(speed) -- "10 m/s"

local power = MetricUnit.new(3, "kilowattHour") / MetricUnit.hours(1)
power:In("kilowatt") -- 3

local reach = MetricUnit.expect(MetricUnit.studs(100), "length", "reach") -- 28, in metres

local swing = MetricUnit.difference(12, "celsius")
(MetricUnit.celsius(15) + swing):In("celsius") -- 27
(MetricUnit.celsius(15) - MetricUnit.celsius(10)):In("kelvin") -- 5

Time is elapsed time in exact seconds. MetricUnit.years and MetricUnit.months are averages for long-range math (a Julian year of 365.25 days, and a twelfth of it), not calendar spans; move a date by calendar months with Time.add from @quenty/time. MetricUnit.InSeconds hands exact seconds to task.wait, os.time and TimeDurationUtils. MetricUnit.instant makes a point in time on any epoch, and MetricUnit.fromDateTime and MetricUnit.ToDateTime cross to and from DateTime.

MetricUnit.format writes a value for players, localized, and MetricUnit.parse reads one back. A value is written in the system of the unit it was made from (miles stay miles, studs stay studs), and metric when made from a metric unit. Convert it (MetricUnit.ToMetric, MetricUnit.ToImperial) or pin one unit (MetricUnit.As) to write it otherwise; the locale never chooses. tostring is a fixed English debug string.

Luau cannot compare a table with a number, so x < 0 and x == 0 do not work; use MetricUnit.sign and MetricUnit.isZero.

instant​

</>
MetricUnit.instant(
seconds: number--

since the epoch

) → MetricUnit

The instant seconds after an epoch: a point in time rather than a span of it. The epoch is whatever the caller measures from, such as a simulation's start; MetricUnit.fromDateTime uses the Unix epoch. Instants follow the same rules as absolute temperatures: two subtract to a span, an instant and a span add to an instant, and an instant cannot be added to another, scaled or negated. Instants from different epochs must not be mixed; nothing can check that for you. 

local worldStart = MetricUnit.instant(0)
local now = worldStart + MetricUnit.years(250)
(now - worldStart):In("year") -- 250
now:In("year") -- 250, time since its epoch

</>
